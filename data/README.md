# FreightIQ Data

This directory contains research and structured datasets used by FreightIQ.

## Structure

- `raw/` — Original source files and research material collected from official sources.
- `processed/` — Cleaned and structured datasets ready for use by FreightIQ.

## Port Data

Port datasets are stored under:

- `raw/ports/`
- `processed/ports/`

Port data will initially focus on:
- Paradip
- Visakhapatnam
- Gopalpur
- Dhamra
- Gangavaram
- Haldia

Only verified data should be added to processed datasets. Unknown or unavailable values should remain empty/null rather than being invented.
